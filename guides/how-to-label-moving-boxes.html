How to label moving boxes so you can find anything

"Kitchen" written on 14 boxes doesn't help when you need the kettle on the first night. Here's a system that does.

1. Number every box

Write a big number on two sides and the top. Numbers let you count that every box arrived and point to exactly the one you need.

2. Color-code by room

One color per room, and the same color on that room's door at the new place. Movers and friends can drop boxes in the right room without asking.

3. Keep a list of what's inside each box

This is the step everyone skips, and the one that saves the most time. Write down what goes in each box as you pack it, not after.

4. Use a QR code so the list travels with the box

Packed prints a label for each box with the number, room color and a QR code. Anyone can scan a box with a normal phone camera to see what's inside, with no app needed. You can also search every box from your phone ("passport", "drill") to see which box it's in.

5. Mark the special boxes

  • Open first: chargers, toilet paper, towels, a kettle, bedding, medicine, basic tools
  • Fragile: mark all sides, not only the top
  • Documents and valuables: keep them with you, not on the truck

6. Print an inventory for the move

A one-page list of every box and its contents helps you check deliveries and makes an insurance claim much easier if something goes missing.
